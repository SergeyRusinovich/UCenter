# 0013. Quality gates: tests without hardware, sanitizers, fuzzing, CI

- **Status:** Accepted
- **Date:** 2026-10-11

## Context

The riskiest code reads untrusted bytes from a serial port and coordinates two threads. A receiver is not always at hand, and CI runners never have one.

## Decision

- **Unit tests** (`test_core`, Qt Test) cover the core logic; UBX frames are compared with reference frames generated by pyubx2.
- **End-to-end session tests** (`test_session`, macOS and Linux) use a pseudo-terminal (`openpty`) as the "USB port": the real `ReceiverSession`, reader thread and `QSerialPort` are exercised, including ACK, a missing ACK, recording, replay and reconnecting.
- **Sanitizers**: tests run under AddressSanitizer and UBSan in CI.
- **Fuzzing**: `fuzz_frame_reader` (libFuzzer) feeds arbitrary bytes in arbitrary chunk sizes through the frame reader, the decoders, the navigation solution and the satellite tracker; a seed corpus is in `fuzz/corpus`. `test_core` also runs a quick deterministic mutation test.
- **Static checks**: compiler warnings (`-Wall -Wextra -Wpedantic -Wshadow`, `/W4`) as errors in CI, clang-tidy ([.clang-tidy](../../.clang-tidy)), clang-format ([.clang-format](../../.clang-format)), complete translations ([0010](0010-localization.md)).
- **CI** ([.github/workflows/ci.yml](../../.github/workflows/ci.yml)) runs all of the above on every push and pull request; macOS and Windows jobs also build packages.

## Alternatives considered

- **Hardware-in-the-loop tests** — the most realistic, but need a runner with a receiver attached; can complement, not replace, the pseudo-terminal tests.
- **Mocking `QSerialPort`** — tests the mock rather than the real port code and threading.

## Consequences

- Changes to parsing or threading are checked automatically without a receiver.
- `test_session` is not available on Windows (no `openpty`).
- On macOS 26 the AddressSanitizer runtime of LLVM 19 hangs at start-up, so the local fuzz build uses UBSan only (`UCENTER_FUZZ_SANITIZERS=undefined`); CI fuzzes on Linux with both.
